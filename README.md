# Banking Analytics — SQL & Power BI

## Project Overview

This project analyzes banking customer, account, transaction, merchant, card, and loan data to identify customer behavior, transaction trends, credit segments, merchant performance, and financial KPIs.

The project combines SQL-based data analysis with Power BI dashboard development to transform raw banking data into actionable business insights.

## Business Objectives

- Analyze customer demographics and financial behavior
- Segment customers based on credit scores
- Understand transaction trends and patterns
- Identify merchant and transaction performance
- Analyze loan-related metrics
- Build interactive dashboards for business decision-making

## Dataset

The project uses multiple interconnected banking datasets including:

- Customers
- Accounts
- Cards
- Merchants
- Transactions
- Loans

## Tools & Technologies

- MySQL
- SQL
- Power BI
- DAX
- Excel

## SQL Analysis

The analysis includes:

- INNER JOIN and LEFT JOIN
- Common Table Expressions (CTEs)
- Subqueries
- Window Functions
- CASE statements
- Aggregations
- Date-based analysis
- Customer segmentation

More than 25 SQL queries were developed to analyze the banking data.

## Customer Segmentation

Customers were segmented based on credit score:

- Excellent: 750+
- Good: 700–749
- Fair: 650–699
- Poor: 600–649
- Very Poor: Below 600
